# CoolSchool

CoolSchool is a GitHub Pages-only local messaging demo inspired by the usability and visual language of modern iOS messaging apps.

## Files

- `index.html`
- `style.css`
- `script.js`

## Hosting

Upload these files to a GitHub repository and enable GitHub Pages. There is no build step, server, backend, database, API, API key, Node.js, or external service.

## Important

Messages and settings are stored locally in the browser with `localStorage`. This is a local/demo messaging experience; it does not provide real online chat or send messages to other users.
